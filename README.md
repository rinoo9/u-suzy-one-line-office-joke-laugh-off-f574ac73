# One-Line Office Joke Laugh-Off

Entry for the [make.fun](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) bounty "One-Line Office Joke Laugh-Off".

`main.py` writes one original one-line office joke to `/output/entry.txt`:

> Our printer only breaks down on deadline day, which is the closest thing this office has to a union rep.

Run it with:

```sh
python3 main.py
```

The output is deterministic: the same joke, byte for byte, on every run.
